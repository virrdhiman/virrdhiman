## About me

I build systems that run before the meeting. I help business owners and leadership teams find where AI and automation will actually pay off, then get it built and adopted.

I've worked where business and technology meet since 2008: first as a software engineer, then four years as an SAP MM consultant, then nearly ten years as Manager (IT & ERP) at Rhiti Group. There I ran ERP operations, MIS reporting and Google Workspace, and cut record-management errors by about 15% with SOPs and cleaner reporting. Since April 2026 I've been an independent consultant on AI, automation and digital transformation.

**How I work:** Diagnose → SOP → Automate → MIS. Process first, tools second.

## Featured project

### [VD Agent (desktop-agent)](https://github.com/virrdhiman/desktop-agent)

A desktop AI coding agent that works with free API keys. It pairs an AI assistant with a Monaco code editor, a terminal and a git client. It reads your code, edits files, runs commands, and checks its own work against your tests and build.

- Automatic model selection and fallback across free providers (for example Groq and Google Gemini), or fully offline with Ollama
- Plan Mode, approval prompts for risky actions, recovery checkpoints, and searchable local chat history
- No account and no telemetry: chats, settings and keys stay on your machine
- Windows, macOS and Linux · TypeScript, React, Electron, Vite
